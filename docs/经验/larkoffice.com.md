# 飞书跨租户文档（larkoffice.com）

依据2026-09-07至09-15本机实测整理。仅处理当前登录用户有权访问、且属于任务范围的分享文档。

## 虚拟滚动会造成「看起来抓全了」

- 后台页可能只渲染部分正文，即使文末提示已出现，也不能据此认定正文完整。
- 需要前台渲染时先告知用户。按目录逐节跳转，收集当前`[data-block-id]`文本并去重，比按初始`scrollHeight`设定一次滚动终点可靠。
- 目录项本轮出现过div与链接两种形态，不写死标签名。检查各节标题、段落及附近的图片和附件块是否齐全。
- 自动滚动循环可能停止推进或漏掉懒加载增长后的内容。检查当前位置与进度，不只看`running`标志。

## 内嵌视频与附件

- 文档渲染后先检查`video.currentSrc`或`video.src`；未加载到的块仍需逐节定位，不能把当前DOM数量当作文档总量。
- 本轮内嵌视频可用`fetch binary:true + savePath + via:"page"`下载，全程无保存框。其它来源先尝试扩展侧fetch；权限或Referer行为以当前响应为准。
- 文件卡片的预览token未必是附件file token。不要猜下载端点；从已授权的附件预览流程与`network`中定位真实请求。
- 原生下载报错时先检查是否仍有下载进行，避免重复提交。媒体地址、文档token与附件名都可能含私人信息，不提交到共享经验库。

## 表单显示值不等于模型值

本轮富文本输入曾显示文字但提交仍判空；合成paste由编辑器自身handler接收后可写入模型。逐栏操作，等待完成并核对当前表单的草稿或刷新回填结果；不要并发运行两个填表循环，也不要批量清除整个站点的localStorage。最终提交以服务端记录为准，并核对已有授权。
