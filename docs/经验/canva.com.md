# Canva（canva.com）

依据2026-09-25本机实测整理。以下类名与内部结构可能随改版变化，先在当前页面确认。

## 原生画笔与坐标

- 中文编辑器曾从「工具→画笔」进入；画笔设置可调粗细、透明度，颜色面板可输入十六进制颜色。
- 本轮绘图事件面为`.l8IkMQ`，设计坐标容器为`._14BoqA`；向事件面派发PointerEvent的pointerdown→pointermove→pointerup可生成可保存的原生笔触。先用少量笔触确认当前版本是否接受这些事件。
- 用当前画布的`getBoundingClientRect()`映射设计坐标；改变窗口、缩放或布局后重新取值，不复用截图像素坐标。
- 连续绘制后立即开换色面板可能遇到渲染未就绪。等待颜色输入框出现，设置后回读画笔颜色标识；不能只以事件成功发出为依据。

## 数量、截图与保存

- 本轮约3200个笔触时出现数量限制警告，未测硬上限，不能将该数字作为产品规格。大任务可考虑分层；压平会失去逐笔编辑能力，需保留矢量备份，并在任务允许时采用。
- 本轮持续采集缩放截图时出现画面裁切；新开已保存设计并改用`full:true`后未再复现，尚未隔离具体原因。截图逐张检查内容，不能把参数选择当作绝对保证。
- 收尾在新标签页重新打开同一设计，确认云端保存与实际内容；当前页面里看得到不等于已持久化。
