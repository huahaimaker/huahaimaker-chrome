# LibTV（liblib.tv）

依据2026-09-21本机实测整理。项目管理和模型调用若已有官方CLI，优先用其结构化接口；浏览器用于核验界面状态。

## 网页与CLI不要同时写同一画布

本轮网页打开同一项目时，前端旧状态会覆盖CLI刚修改的节点参数。执行已获授权的参数修改前，先结束网页中未保存的编辑并离开该画布，再通过CLI修改；完成后重新打开核对。不要直接改DOM的viewport transform充当已保存的画布设置。

## 3D视口与下载

- `screenshot.savePath`本轮已能写盘。WebGL区域在本轮`full:true`截图里出现过空白，默认JPEG路径能取到；两个路径都需检查实际画面，不能只看文件存在。
- 3D-BOX任务在后台页曾停止推进，切前台后恢复。需要前台时先告知用户会占用焦点。`DIALOG_BLOCKING`先检查是否真有弹窗，不凭这条历史经验跳过验证。
- 「导出」按钮无结果不证明生成失败。先查询节点状态及媒体URL；签名URL仅用于当前下载，不写入共享经验。
- 下载优先尝试`fetch`的`binary:true`与`savePath`，必要时尝试`via:"page"`。原生`download`可能弹系统保存框。
- 本轮部分生成视频进入「创意片头」时报截帧失败，将已下载的视频重新上传为新节点后可用。这会新建资产；仅在任务允许时采用，不自动重生成或重复扣费。
