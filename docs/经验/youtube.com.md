# YouTube Studio（studio.youtube.com）

依据2026-09-18本机实测整理。步骤会受账号资格、界面版本和视频类型影响。

## 注入失败时换工具

本轮`eval`被Trusted Types限制，简单表达式也失败。遇到同样错误时用`snapshot`、`query`、`click`、`type`或`act.find`，不反复换表达式重试。不要把一次环境结果写成所有版本永远不可用。

## 上传、草稿与排定

- 上传对话框打开后先找file input，用`upload`注入；点「选择文件」可能打开扩展无法操作的系统文件框。
- 每走完一步重新snapshot。按钮不可用时，先检查前面步骤是否有未完成项，不能只等视频处理进度。
- 本轮「预定」未解锁与创收设置、自评步骤未完成有关。是否创收、自评选项必须依据用户决定和实际内容填写；不能机械选择「以上都没有」。并非每个账号都出现相同步骤。
- 草稿从内容列表的「编辑草稿／继续上传」恢复。本轮直接访问普通视频编辑链接会失败。
- 定时时间要读取页面显示的时区，不能假设它等于电脑时区。
- 保存后在Studio内容列表核对排定状态与日期时间。主站是否登录和公开播放页能否打开，不能单独证明Studio里的定时设置成功或失败。
