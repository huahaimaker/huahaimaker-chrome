# 抖音创作者中心（creator.douyin.com）

依据2026-09-18、09-22本机实测整理。页面、按钮名称及审核行为可能变化，以当前状态为准。发布或重新提交只在用户授权范围内执行。

## 换封面：选对上传区，区分暂存与提交

- 编辑页可能同时存在视频、横封面、竖封面等多个`input[type=file]`。指定当前封面编辑器里的selector；本轮使用`dropSelector`定位「点击上传文件或拖拽文件到这里」区域可成功上传。
- 临时标记的元素可能因重渲染失效。上传后核对预览及缩略图URL的路径部分，签名query变化不能证明封面已变。
- 封面弹层里的「完成」只更新当前表单。本轮仍需页面底部「发布」才提交服务器；刷新或重新进入内容管理验证持久化。
- 提交前对比标题、简介、定时时间等非目标字段。修改已定时作品后，本轮会重新进入「审核中」；不要将其当作无影响的保存操作。
- 本轮重提后编辑链接的`iid`发生变化；旧链接可能打开空白新建表单。优先从内容管理进入，先核对表单内容，不能只凭URL判断目标。

## 检测与页面交互

- 封面弹层的检测与右侧「发文助手」是不同区域；读取结果时限定容器，避免把另一处的「检测通过」误归给目标封面。
- 本轮补边和模糊背景版本仍出现「边框面积过大」，重新按目标比例构图后通过。仅能说明这些样本的结果，不能据此推断检测器算法或所有封面的结果。
- 截图默认可能缩放，点击坐标优先来自当前元素的`getBoundingClientRect()`。异步刷新后重新获取snapshot，避免复用失效ref。
- 审核中若没有编辑入口，查询当前审核状态，不连续重提，也不要把旧链接打开的空白表单当作原作品。
